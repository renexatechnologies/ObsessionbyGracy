## Styling Tokens (required for a premium look)
- Primary dark background: `#0c0a09`
- Accent green: `#8C9567`
- Light background: `#FAF7F2`
- Text primary: `#0c0a09`
- Text secondary / highlights: `#8C9567`
- Dark‑mode backgrounds: `bg-[#0c0a09]` for hero sections, `dark:bg-stone-950` for page backgrounds.
- Rounded corners: `rounded-2xl` for cards, `rounded-full` for icons/buttons.
- Shadows: `shadow-md` (default) and `shadow-xl` on hover.

## Functional Requirements
- **Routing** – React Router v7 routes as listed above.
- **State management** – `CartContext` provides cart state across pages.
- **Form submission** – Bespoke Inquiry form opens a WhatsApp chat with a pre‑filled message.
- **Responsive layout** – Tailwind CSS grid/flex utilities for mobile, tablet and desktop breakpoints.
- **Dark mode support** – Tailwind `dark:` variants used throughout.

- **Hero background images** – optional, can be added via CSS `bg-[url('...')]`.
- **Icons** – Material Symbols used for phone, send, etc.
